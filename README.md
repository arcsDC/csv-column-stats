# csv-column-stats

Compute per-column statistics (count, min, max, mean, median) for numeric and text fields in a CSV file.

## Stack

Primary language: **Python**

## Project structure

- `main.py` — Read a CSV file and output a JSON summary of per-column statistics, distinguishing numeric from text columns.
- `requirements.txt` — Declare that the project uses only the Python standard library, so no external packages are required.

## Usage

Review the source files and install any dependencies referenced by the project before running it.
